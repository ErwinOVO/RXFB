# 法律法规库

金融监管法规的采集、清洗、入库与全文检索。主库 `法规库.db`（SQLite + FTS5）。

## 跑起来

```bash
python backend/检索服务.py     # http://127.0.0.1:8765
```

`法规库.db` 已随仓库提供（Git LFS），开箱即用。

## 三阶段流水线

需要重新采数据 / 更新库时，按顺序执行：

| 脚本 | 阶段 | 做什么 |
|---|---|---|
| `爬数据.py` | 一 | 抓金监总局官网 / 人行官网 / iweicha；下载附件，提取 PDF 正文与 OCR |
| `处理数据.py` | 二 | 跨源合并去重、正文体检、生成排除清单 → `待入库_v2/` |
| `入库.py` | 三 | schema 迁移、灌库、字段回填、分类、索引 → `法规库.db` |

```bash
python 爬数据.py
python 处理数据.py
python 入库.py
```

每个脚本都支持 `--dry-run`（只分析不写）与 `--only`（只跑某几步），详见 [`脚本说明.md`](脚本说明.md)。
