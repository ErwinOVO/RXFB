金融监管领域的知识库，按模块分目录组织。

| 目录 | 内容 | 状态 |
|---|---|---|
| [`法律法规库/`](法律法规库/) | 金融监管法规：采集 → 清洗 → 入库 → 检索 | 已完成（2897 条） |
| `处罚案例库/` | 金融处罚案例的采集与检索 | 建设中 |

## 法律法规库 · 快速开始

依赖 Python 3.10+。

主库 `法规库.db`（90 MB）由 **Git LFS** 托管。克隆前请先装 Git LFS，否则拿到的只是一个指针文件、不是数据库：

```bash
git lfs install
git clone https://github.com/ErwinOVO/RXFB.git
cd RXFB/法律法规库
```

### 直接用检索服务

仓库已带 `法规库.db`，**不需要重新采集**：

```bash
python backend/检索服务.py     # 默认 http://127.0.0.1:8765
```

### 从零重建数据

三个阶段按顺序执行。每个脚本单文件自包含，每步幂等，可重复跑：

```bash
python 爬数据.py      # 阶段一：金监总局 / 人行官网 / iweicha 抓取，附件正文 + OCR
python 处理数据.py    # 阶段二：跨源合并去重、正文体检、生成排除清单
python 入库.py        # 阶段三：schema 迁移、灌库、字段回填、分类、索引
```

完整说明见 [`法律法规库/脚本说明.md`](法律法规库/脚本说明.md)。

## 仓库说明

- **不入库的内容**：原始爬取数据（约 650 MB）、处理产物、合并前的历史脚本备份。体积大且可由上面的脚本重建，已在 `.gitignore` 中排除。
- **`.workbuddy/`** 是本地工具目录，与仓库内容无关。
- 原始爬取数据虽然可重建，但重建**依赖来源网站的可用性**（金监总局官网有 WAF 限速、iweicha 部分原文链接取不到），并非随时可重跑。迁移环境时建议单独打包备份。
